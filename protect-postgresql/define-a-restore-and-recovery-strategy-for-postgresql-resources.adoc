= Definire una strategia di ripristino e recupero per le risorse PostgreSQL
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È necessario definire una strategia prima di ripristinare e recuperare il cluster, in modo da poter eseguire correttamente le operazioni di ripristino e recupero.


NOTE: È supportato solo il ripristino manuale del cluster.

.Passi
. Determinare le strategie di ripristino supportate per le risorse PostgreSQL aggiunte manualmente
. Determinare le strategie di ripristino supportate per i cluster PostgreSQL rilevati automaticamente
. Decidi il tipo di operazioni di ripristino che vuoi eseguire.
