= Configurare le credenziali per una singola risorsa di SQL Server
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile configurare le credenziali per eseguire processi di protezione dei dati su singole risorse di SQL Server per ciascun utente.  Sebbene sia possibile configurare le credenziali a livello globale, potrebbe essere opportuno farlo solo per una risorsa specifica.

.Informazioni su questo compito
* Se si utilizzano le credenziali di Windows per l'autenticazione, è necessario impostare le credenziali prima di installare i plug-in.
+
Tuttavia, se si utilizza un'istanza di SQL Server per l'autenticazione, è necessario aggiungere le credenziali dopo aver installato i plug-in.

* Se hai abilitato l'autenticazione SQL durante la configurazione delle credenziali, l'istanza o il database individuato viene visualizzato con un'icona a forma di lucchetto rosso.
+
Se viene visualizzata l'icona del lucchetto, è necessario specificare le credenziali dell'istanza o del database per aggiungere correttamente l'istanza o il database a un gruppo di risorse.

* È necessario assegnare le credenziali a un utente con controllo degli accessi basato sui ruoli (RBAC) senza accesso sysadmin quando sono soddisfatte le seguenti condizioni:
+
** La credenziale viene assegnata a un'istanza SQL.
** L'istanza o l'host SQL viene assegnato a un utente RBAC.
+
L'utente deve disporre sia dei privilegi di gruppo di risorse che di backup.







== Passaggio 1: aggiungere e configurare le credenziali

. Nel riquadro di navigazione a sinistra, seleziona *Impostazioni*.
. Nella pagina Impostazioni, seleziona *Credenziali*.
+
.. Per aggiungere una nuova credenziale, seleziona *Nuovo*.
.. Nella pagina Credenziali, configura le credenziali:
+
[cols="1,3"]
|===
| Per questo campo... | Fai questo... 


 a| 
Nome della credenziale
 a| 
Inserisci un nome per le credenziali.



 a| 
Nome utente
 a| 
Immettere il nome utente utilizzato per l'autenticazione di SQL Server.

*** Amministratore di dominio o qualsiasi membro del gruppo di amministratori Specificare l'amministratore di dominio o qualsiasi membro del gruppo di amministratori sul sistema su cui si sta installando il plug-in SnapCenter . I formati validi per il campo *Nome utente* sono:
+
**** _NetBIOS\NomeUtente_
**** _FQDN dominio\Nome utente_


*** Amministratore locale (solo per gruppi di lavoro) Per i sistemi che appartengono a un gruppo di lavoro, specificare l'amministratore locale integrato nel sistema su cui si sta installando il plug-in SnapCenter . È possibile specificare un account utente locale appartenente al gruppo degli amministratori locali se l'account utente dispone di privilegi elevati o se la funzionalità di controllo degli accessi utente è disabilitata sul sistema host.  Il formato valido per il campo *Nome utente* è: _NomeUtente_




 a| 
Password
 a| 
Inserisci la password utilizzata per l'autenticazione.



 a| 
Modalità di autenticazione
 a| 
Selezionare la modalità di autenticazione di SQL Server.  È anche possibile scegliere l'autenticazione Windows se l'utente Windows dispone dei privilegi di amministratore di sistema sul server SQL.



 a| 
Ospite
 a| 
Selezionare l'host.



 a| 
Istanza di SQL Server
 a| 
Selezionare l'istanza di SQL Server.

|===
.. Selezionare *OK* per aggiungere le credenziali.






== Passaggio 2: configurare le istanze

. Nel riquadro di navigazione a sinistra, seleziona *Risorse*.
. Nella pagina Risorse, seleziona *Istanza* dall'elenco *Visualizza*.
+
.. Selezionare image::../media/filter_icon.png[icona filtro], quindi selezionare il nome host per filtrare le istanze.
.. Selezionare image::../media/filter_icon.png[icona filtro] per chiudere il riquadro filtro.


. Nella pagina Protezione istanza, proteggi l'istanza e, se necessario, seleziona *Configura credenziali*.
+
Se l'utente che ha effettuato l'accesso a SnapCenter Server non ha accesso a SnapCenter Plugin per Microsoft SQL Server, dovrà configurare le credenziali.

+

NOTE: L'opzione delle credenziali non si applica ai database e ai gruppi di disponibilità.

. Seleziona *Aggiorna risorse*.
