= Più database sullo stesso volume
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile posizionare tutti i database sullo stesso volume, poiché la policy di backup prevede un'opzione per impostare il numero massimo di database per backup (il valore predefinito è 100).

Ad esempio, se si hanno 200 database nello stesso volume, vengono creati due snapshot con 100 database in ciascuno dei due snapshot.
