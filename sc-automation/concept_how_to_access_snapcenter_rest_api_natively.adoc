= Come accedere in modo nativo all'API REST di SnapCenter
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile accedere direttamente all'API REST SnapCenter utilizzando qualsiasi linguaggio di programmazione che supporti un client REST.  I linguaggi più diffusi sono Python, PowerShell e Java.
