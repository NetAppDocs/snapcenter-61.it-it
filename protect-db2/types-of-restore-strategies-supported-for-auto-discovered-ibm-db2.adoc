= Tipo di strategia di ripristino supportata per IBM Db2 rilevato automaticamente
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È necessario definire una strategia prima di poter eseguire correttamente le operazioni di ripristino utilizzando SnapCenter.

Il ripristino completo delle risorse è la strategia di ripristino supportata per i database IBM Db2 rilevati automaticamente.  Ripristina tutti i volumi, i qtree e i LUN di una risorsa.
