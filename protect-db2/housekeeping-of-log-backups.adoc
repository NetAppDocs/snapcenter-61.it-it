= Come SnapCenter gestisce la manutenzione dei backup dei dati
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapCenter gestisce la manutenzione dei backup dei dati a livello di sistema di archiviazione e di file system.

Gli snapshot sullo storage primario o secondario e le voci corrispondenti nel catalogo IBM Db2 vengono eliminati in base alle impostazioni di conservazione.
