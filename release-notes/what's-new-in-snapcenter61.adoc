= Novità del SnapCenter software 6.1
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La versione 6.1 del SnapCenter software include numerose nuove funzionalità e miglioramenti.

|===
| Aggiornamento | Descrizione 


| link:../get-started/reference_supported_storage_systems_and_applications.html["Supporto per sistemi ASA r2"]  a| 
SnapCenter supporta ora i sistemi ASA r2 che creano un'esperienza semplificata specifica per le esigenze dei clienti SAN-only.



| Supporta snapshot secondari antimanomissione  a| 
SnapCenter consente di specificare il periodo di blocco per gli snapshot secondari.

|===
