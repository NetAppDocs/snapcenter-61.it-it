= Rilevamento automatico delle risorse sull'host Linux
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le risorse sono istanze MySQL sull'host Linux gestite da SnapCenter.  Dopo aver installato il plug-in SnapCenter per MySQL, le istanze MySQL su quell'host Linux vengono automaticamente rilevate e visualizzate nella pagina Risorse.
