= Disinstallare il pacchetto plug-in per Linux o AIX tramite CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile disinstallare SnapCenter Plug-ins Package per Linux o SnapCenter Plug-ins Package per AIX utilizzando l'interfaccia della riga di comando.

.Prima di iniziare
* Assicurati di aver eliminato i lavori pianificati
* Assicurarsi che tutti i lavori in esecuzione siano completati.


.Fare un passo
Eseguire _/custom_location/ NetApp/snapcenter/spl/installation/plugins/uninstall_ per disinstallare.
