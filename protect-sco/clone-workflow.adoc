= Flusso di lavoro di clonazione
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il flusso di lavoro della clonazione comprende la pianificazione, l'esecuzione dell'operazione di clonazione e il monitoraggio dell'operazione.

È possibile clonare i database per i seguenti motivi:

* Per testare le funzionalità che devono essere implementate utilizzando la struttura e il contenuto del database corrente durante i cicli di sviluppo delle applicazioni.
* Per popolare i data warehouse utilizzando strumenti di estrazione e manipolazione dei dati.
* Per recuperare dati cancellati o modificati per errore.
